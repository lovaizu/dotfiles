# Goal

ソフトウェアの名前で覚えた技法のうち、ソフトウェアの外でも成り立つものを `claude/CLAUDE.md` に、
ソフトウェアの言葉を使わずに書く(Issue #20)。
いまは学んだ場所で仕分けられていて(GWT をテストの知識として skill へ送った lovaizu/ccpm#27 など)、
どの作業にも効く規則が、毎回読まれる層に無い。

この層は毎回読まれ、短いことに価値がある。基準なしに増やすと読まれなくなる。

# Acceptance criteria

- 足す・広げる各行は、元の分野の言葉を抜いて書いても中身が残る(Issue の言い換えテスト)
- 既存の行が狭い形で同じことを言っているなら、新しい行を足さずにその行を広げている
- 既存の行から既に言えることは足していない
- 候補ごとに、採る・採らない・既存の行に含めるの判断と理由がユーザーに承認されている
- 足した行が、ソフトウェアでない作業を `claude -p` で与えたとき、変更前と比べて振る舞いを変える
- 既存の行の意味は変わらない

# Assumptions

- Fact(`setup.sh` で配置): `claude/CLAUDE.md` は `~/.claude/CLAUDE.md` として全プロジェクトで読まれる
- Fact(Issue #20): 候補は DRY / GWT / 作り直さない / 小さい単位 / 冪等 / 関心の分離 / 境界 / YAGNI の8つ
- Assumption: PR #30・#32 と同じく、`claude -p` で変更前後を比べれば効き目が見える

# Rules

- commit and push every change
- 会話・`.rn/` は日本語。CLAUDE.md・コミット・PR は英語
- 過去セッションの `.rn/` は読むだけで書き換えない
- README は変えない(読み手が見落として誤る点が増えないため)
- レビューは目的に照らして効く指摘だけ。1人用 dotfiles
- 判断は1件ずつユーザーに聞く
