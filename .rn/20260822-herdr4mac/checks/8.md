## setup.sh と突き合わせた記述

| README の記述 | 当てた setup.sh の箇所 |
|---|---|
| herdr の配置先は `${XDG_CONFIG_HOME:-$HOME/.config}/herdr/config.toml` | L75-76 `set_xdg_base XDG_CONFIG_HOME ... "$HOME/.config"` / `HERDR_CONFIG="$xdg_base/herdr/config.toml"`(理由のコメント L67-74) |
| iTerm2 の配置先は `~/Library/Application Support/iTerm2/DynamicProfiles/herdr.json` | Darwin arm の `iterm_dir="$HOME/Library/Application Support/iTerm2/DynamicProfiles"` + `deploy ... "$iterm_dir/herdr.json"` |
| WT の配置先は `%LOCALAPPDATA%\Packages\Microsoft.WindowsTerminal_8wekyb3d8bbwe\LocalState\settings.json` | 非 Darwin arm の `wt_dir="$appdata/Packages/Microsoft.WindowsTerminal_8wekyb3d8bbwe/LocalState"` + `deploy ... "$wt_dir/settings.json"` |
| 絶対パスでない XDG 値は無視して既定値に戻し、そのことを警告する | `set_xdg_base`(L53-69、`case "$value" in /*)` L55-60)と `if [ -n "${XDG_IGNORED:-}" ]; then warn ...` |
| 丸ごと上書き、部分マージはしない。配置先にしか無い設定は消える | `deploy` 直前のコメント「dotfiles is the source of truth, so the whole file is replaced: a setting made on the machine that dotfiles does not carry does not survive the next run -- to keep one, put it in dotfiles.」 |
| 既に同一なら何もしない | `deploy` の `if cmp -s "$src" "$dst" ...; then echo "Up to date: $dst"; return 0; fi` |
| 退避先は `${XDG_STATE_HOME:-$HOME/.local/state}/dotfiles-backups`、退避したらパスを表示 | `set_xdg_base XDG_STATE_HOME ... "$HOME/.local/state"` / `BACKUP_DIR="$xdg_base/dotfiles-backups"`、`echo "Backed up the previous $dst to $backup"` |
| 既存ファイルが無いとき、および既に同一で上書きが起きないときは退避しない | `backup_file` の `[ -e "$dst" ] || return 0`、および上の `cmp -s` 早期 return(バックアップに到達しない) |
| 退避は Mac も WSL も同じ扱い | 管理対象はすべて同一の `deploy` を通る(`deploy` のコメント「Every managed file is deployed by this one call, and by nothing else.」)。`BACKUP_DIR` は OS 分岐の外で1つだけ決まる |
| 退避ファイルは剪定しない | `.bak` を消す箇所は `deploy` 失敗時の自分の分の `rm -f "$backup"` のみ。`sweep_tmp_files` が消すのは一時ファイルで `.bak` ではない。世代数・日数による削除は無い |
| 失敗しても続行し、最後に列挙して非 0 で終了 | `record_failure` のコメント「A deployment that fails is a warning and the setup carries on」、末尾の `if [ "${#FAILURES[@]}" -gt 0 ]; then ... echo "Finished with ... failure(s):" ... exit 1` |
| 非 WSL Linux / WT 未導入はスキップで、終了コードは 0 | `echo "Not WSL. Skipping Windows Terminal." >&2` と `echo "Windows Terminal not installed ($wt_dir does not exist). Skipping." >&2`(どちらも `record_failure` を呼ばない → `FAILURES` 空 → `echo "Done."` で 0) |
| Dynamic Profile は iTerm2 が未導入でも配置する | Darwin arm のコメント「The profile is deployed whether or not iTerm2 is on this machine ... iTerm2 reads the directory when it is next started」 |
| Homebrew が無い / install 失敗は警告のみで失敗に数えない | Darwin arm の `if command -v brew ... elif ! brew install --cask font-hackgen-nerd; then warn ...` / `else warn "Homebrew is not installed, ..."`。いずれも `warn` で `record_failure` ではない。コメント「the font is not a managed file ... this run is not counted a failure」 |
| herdr がデフォルトプロファイルでない場合に警告。iTerm2 の設定が無いマシンでは「どれがデフォルトか分からない」旨を出す。どちらも失敗ではない | Darwin arm の `if default_guid="$(defaults read com.googlecode.iterm2 "Default Bookmark Guid" ...)"` の2分岐。どちらも `warn` |
| 配置先が symlink で中身が違うときはリンクが通常ファイルに置き換わり、リンク先はそのまま残る。退避はリンク先の内容なので戻してもリンクは戻らない。指す先が無いリンクは退避が取られない。中身が一致しているリンクはそのまま残る。失敗ではなく警告で、必要なら自分で張り直す | `deploy` の `if [ -n "$was_link" ]; then warn "$dst was a symlink and is not one any more." ...`(L528-537、`Fix: if the link was wanted, make it again now.`)。リンク先が残る点と一致判定でここに到達しない点は同じブロックのコメント「what it pointed at was left as it was」「A link whose target already held the dotfiles copy never reaches this: the cmp above reads through it and returns」。dangling リンクで退避が取られないのは `backup_file` の `[ -e "$dst" ] || return 0`(`design.md` §4.6 の境界 (c))。`warn` であって `record_failure` ではないことは L275-283 の3分類コメント |

補足: `design.md` §4.6 の「配置方式は1種類だけで、ファイルごとの例外を持たない」「BACKUP_DIR はどのプログラムも読まない」と、退避を OS 別ではなく配置方式の説明として1か所に書いた構成が一致する。§4.7 の「README はこの2層について設定箇所だけを書く」も維持。
