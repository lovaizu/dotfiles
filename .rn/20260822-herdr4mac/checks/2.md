# #2 レビュー

| 指摘 | 対応要否 | 対応内容 |
|---|---|---|
| `Cursor Text Color` が未設定 | **見送り**(完了基準が ANSI 16 色 + 前景/背景/カーソル/選択に限られていたため範囲外と判断) | — |
| 色の float 精度の桁数、`Alpha Component` の int/float 混在 | 見送り(Low、描画に影響しない) | — |
| `plutil -lint` が失敗する | 不要(欠陥ではない) | iTerm2 は DynamicProfiles を NSJSONSerialization で読む。検証は JSON として行う(design.md §4.3) |

**見送り判断が誤りだった**: 未定義の色キーは iTerm2 の Default プロファイル(Catppuccin Latte)から
引き継がれ、Gruvbox Dark の背景に対して読めなくなる。`Cursor Text Color` は実際にその1つで、
#11 で `Bold Color` `Badge Color` とともに追加した。**完了基準が「定義した色が正しいか」しか問うて
おらず、「定義していない色がどうなるか」を問わなかった**のが原因 — #11 の完了基準はそこを問う形に
書き換えてある。
