# Review

This repository has one user and two machines. On each machine, the user runs `./setup.sh` by hand a few times a year. Each sandbox also runs `./setup.sh` at the creation of the sandbox. Each time the sandbox starts, it pulls main and runs `./setup.sh` again. Use these facts to report only the review findings that affect the goal. Give these facts in the request when you ask for a review. Never use them as a reason not to fix something. Check the technical reason itself first. Both mistakes have happened before. Some review rounds went to findings that didn't affect the goal. In PR #11, a review round turned down a split of `setup.sh` only because of these facts.
