# Review

This repository has one user, two machines, and `chezmoi apply` run by hand a few times a year. Use that to keep review findings to what affects the goal, and say it in the request when asking for a review. Never use it as a reason not to fix something: check the technical reason itself first. Both have happened: review rounds spent on findings that did not affect the goal, and in PR #11 a split of `setup.sh` turned down on that ground.
