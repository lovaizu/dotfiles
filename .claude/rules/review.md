# Review

This repository has one user and two machines. On each machine, the user runs `./setup.sh` by hand a few times a year. Each sandbox also runs `./setup.sh` when the sandbox is created. Each time the sandbox starts, it gets the latest main and runs `./setup.sh` again. Use these facts to report only the review findings that affect the goal. Give these facts in the request when you ask for a review. Never use them as a reason not to fix something. Check the technical reason itself first. Both mistakes have happened before. Some review rounds were spent on findings that did not affect the goal. In PR #11, a split of `setup.sh` was turned down only because of these facts.
