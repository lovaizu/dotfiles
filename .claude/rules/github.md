# Commits and pull requests

- What stays in the repository (code, comments, commit messages, README, issues, PR descriptions) is in English. The conversation, replies to PR review comments and the `.rn/` session notes are in Japanese. Replies drifted into English more than once.
- A process fix that comes out of the work at hand and can be made right away goes into the same PR, as `.claude/rules/readme.md` did in PR #28. Anything else gets its own issue: a PR mixes only what belongs to its work.
